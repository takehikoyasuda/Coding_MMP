Worked examples

Six worked examples that these packages compute, each with the Macaulay2 session that computes it.

Every example has two parts. First a short explanation of the mathematics. Then the session that does the computation. The sessions are real: the input files in examples/*.m2 are given to Macaulay2, and the output is saved exactly as Macaulay2 printed it. Each session is folded, with its main results shown on the fold. Click one to read all of it. The algorithms and their proofs are in the paper (arXiv:2603.13703).

In every example, $X$ is a normal projective threefold and $R$ is its homogeneous coordinate ring. $K_X$ is the canonical divisor and $H$ is an ample Cartier divisor. The nef threshold is

$$\lambda = \min\{\,t \ge 0 \;:\; K_X + tH \text{ is nef}\,\}.$$

$X$ has to be normal and log terminal. The package assumes this. It does not check it.

In the paper, $X = \Proj R$ is monograded. A bigraded ring appears only as the graph of a morphism, which is how the Stein factorization is computed. Every example here stays inside that setting. The package also has entry points that take a multigraded variety directly. Those go beyond the paper, and this page does not use them.

1. Projective space

Here $X = \PP^3$ and $K_X = -4H$, where $H$ is the hyperplane class. The example asks three questions.

Is $K_X$ nef? No. The package tests the divisor $K_X + \tfrac12 H$. It checks the first six multiples of that divisor, and none of them is base point free. Six is enough: the effective base point free theorem says so for this case. So $K_X + \tfrac12 H$ is not nef. If $K_X$ were nef, then $K_X + \tfrac12 H$ would be nef too, because $H$ is ample. So $K_X$ is not nef.

What is the nef threshold? $K_X + tH = (t-4)H$, which is nef exactly when $t \ge 4$. So $\lambda = 4$, and the package finds $4$.

What does $K_X + \lambda H$ contract? $K_X + 4H = 0$. It is base point free, and its linear system sends $X$ to one point. This is a fibre type contraction, and the dimension drops by $3$. The MMP driver stops here, after one step, at a $K$-negative fibration.

2. A quintic threefold

$X$ is a smooth quintic in $\PP^4$. By adjunction $K_X = (5-5)H = 0$.

The package tests the pluricanonical divisors first. The first one is $K_X$ itself, and it is base point free. So $K_X$ is nef and $X$ is already a minimal model. The driver stops after zero steps.

3. The Segre threefold

$X = \PP^1 \times \PP^2$, embedded in $\PP^5$ by the Segre map. So $R$ is the quotient by the $2 \times 2$ minors of a $2 \times 3$ matrix of variables.

Here $K_X = \OO(-2,-3)$ and $H = \OO(1,1)$, so $K_X + tH = \OO(t-2,\,t-3)$. This is nef exactly when $t \ge 3$. The package computes $\lambda = 3$, and then computes the contraction given by

$$K_X + 3H = \OO(1,0).$$

The linear system of $\OO(1,0)$ is the projection $X \to \PP^1$. The package finds a fibre type contraction with target dimension $1$.

This time the target is not a point, so there is a Stein factorization to compute. The bound that certifies it is computed too, not assumed. Here the factorization is trivial, because $\mathrm{pr}_1$ already has connected fibres. Example 4 is the same $X$ with a map whose fibres are not connected.

4. A map with disconnected fibres

Stein factorization writes a map $f : Y \to W$ as $f = g \circ h$, where $h$ has connected fibres and $g$ is finite. In examples 3 and 5 the finite map $g$ turns out to be an isomorphism, so the factorization does nothing. This example is one where it does something.

Take $Y = \PP^1 \times \PP^2$ again, and the map

$$f : Y \to \PP^1, \qquad ([s_0:s_1],\,x) \longmapsto [s_0^2 : s_1^2].$$

Over a point of $\PP^1$ other than $[1:0]$ and $[0:1]$, the square map has two preimages, so the fibre of $f$ is two disjoint copies of $\PP^2$. Over those two points the fibre is one copy. The session checks this first, with no help from the package: it decomposes the fibre over $t_0 = t_1$ and gets two pieces, and the fibre over $t_1 = 0$ and gets one.

So $f$ does not have connected fibres, and the factorization has to be

$$Y \;\xrightarrow{\ h = \mathrm{pr}_1\ }\; \PP^1 \;\xrightarrow{\ g = \text{squaring}\ }\; \PP^1 .$$

The package finds exactly this. The middle variety $Z$ has dimension $1$, and $Y$ has dimension $3$, so $h$ has relative dimension $2$. The target also has dimension $1$, so $g$ is finite. And the Stein algebra has rank $2$ over the coordinate ring of the target, which is the degree of $g$. Degree $2$ means $g$ is not an isomorphism.

The same rank is $1$ in example 5, where $g$ is an isomorphism.

5. Blowing up a line, and a two-step program

$Y$ is the blow up of $\PP^3$ along a line, and $f : Y \to \PP^3$ is the map. The package is given one thing only: a parametrization of the graph of $f$. Nothing about $f$ is stated. The graph lives in a bigraded ring, where the first block of variables is the source and the second block is the target. This is how the paper writes a morphism.

Stein factorization. Write $f = g \circ h$, where $h$ has connected fibres and $g$ is finite. The package computes the coordinate ring of the middle variety $Z$. Two things come out of it. First, $\dim Z = 3$. Since $\dim Y = 3$ as well, the dimension does not drop, so $f$ is birational. Second, the ring of $Z$ is monograded, so the program can go on from $Z$ without any further work.

Is the contraction small? A birational contraction is called small when its exceptional locus has codimension $2$ or more. A small contraction needs a flip. A divisorial one does not. The package finds the exceptional locus as the support of $\bigwedge^2 \Omega_{Y/Z}$.

For this $f$ the exceptional locus is the exceptional divisor $E$. The package finds dimension $2$ and codimension $1$, so the contraction is divisorial.

The same test then runs on a small contraction, for comparison. Take the ordinary double point $\{g_0g_1 = g_2g_3\}$ and blow up the ideal $(g_0,g_2)$. This is the standard small resolution. Its exceptional locus is a curve, of dimension $1$ and codimension $2$, so that contraction is small. Example 6 computes a flip for a case like this one.

The program. The relative canonical model over $Z$ is the identity, so no flip is needed and the step is divisorial. The driver then continues from $Z$. It repeats example 1: $\lambda = 4$, and the contraction to a point. The whole program is

$$\mathrm{Bl}_L\PP^3 \;\xrightarrow{\ \text{divisorial}\ }\; \PP^3 \;\xrightarrow{\ \text{fibration}\ }\; \text{point},$$

two steps, ending at a $K$-negative fibration. Every ring in the chain is monograded, and the only bigraded ring is the graph of $f$.

6. A toric flip

Take four rays in $N = \ZZ^3$:

$$v_1 = e_1,\quad v_2 = e_2,\quad v_3 = e_3,\quad v_4 = (1,1,-2).$$

They satisfy one relation, $v_1 + v_2 = 2v_3 + v_4$. Four rays with a single relation of this shape form a circuit. The cone $\sigma$ they span can be triangulated in two ways, and the two results differ by a flip. The cone itself, with no triangulation, is the target of the flipping contraction.

$\sigma$ is not $\QQ$-Gorenstein. To see this, look for an $m$ with $\langle m, v_i \rangle = 1$ for all four rays. The first three rays force $m = (1,1,1)$, but $\langle (1,1,1), v_4 \rangle = 0$. So there is no such $m$.

The example builds this variety in Macaulay2. The dual cone has a Hilbert basis of five elements with three relations, and one more variable $w$ makes a projective threefold $W$. The flip is then computed as the relative canonical model

$$W^{+} = \Proj \bigoplus_{m \ge 0} H^0\bigl(W, \OO_W(mK_W)\bigr).$$

The session checks that this is a real flip: the result is not the identity and not an isomorphism, but it has the same dimension as $W$. The package also writes down the inverse rational map $W \dashrightarrow W^{+}$, checks that its equations hold, and finds its base locus $V(y_4,y_5)$. Recorded as an MMP step, this is a flipping step.

How to repeat these runs

You need Macaulay2 1.26.06 and a checkout with its submodules.

git clone --recurse-submodules https://github.com/takehikoyasuda/Coding_MMP
cd Coding_MMP
examples/run.sh                                   # all six
examples/run.sh examples/01-projective-space.m2   # or one of them

Each run rewrites the .out transcript and the .time file next to its script. This page is built from those files, so it cannot quote output that Macaulay2 no longer prints.

What is not here

These six examples finish. Some other inputs do not. Those cases were measured rather than guessed, and the measurements are in research-log/. What the implementation is tested and trusted to do is listed in docs/IMPLEMENTATION-STATUS.md.

The package's multigraded entry points are also not shown here. They take a multigraded variety as input, which the paper does not, so their examples belong with the package rather than with the paper.
